# 应用 OCR 保底与简洁查询验收记录

## 应用 OCR 保底

- 仅处理当前用户授权、当前位于前台且存在有效客户区的工作进程。
- 专属适配器连续 60 秒没有有效事件后才触发；首次发现的进程同样等待 60 秒。
- Chrome/Edge、安全桌面、UAC、凭据控件、Aetheris 自身和隐藏窗口不触发。
- 单次只截客户区一帧，截图不写盘，OCR 完成或失败后释放图像对象。
- OCR 文本先经过 DLP 和 Redactor，事件仅保留应用名、短窗口上下文、脱敏文本和固定采集方式。
- 同一设备、进程和内容五分钟内只保留一次；队列高水位或 Worker 忙时跳过。
- 本地 Lens 与 Admin Web 展示候选、成功、跳过、失败和最近事件，不展示截图或内部异常。

## 智能查询

| 问题 | 默认模式 | 主答案要求 |
| --- | --- | --- |
| 线路有没有流量限制 | `direct` | 只给存在/不存在结论，最多 80 字 |
| 为什么线路会限速 | `reason` | 最多三个直接原因和引用 |
| 详细说明限速实现和证据 | `analysis` | 允许展开实现细节和证据 |

服务端对模型输出执行 JSON、模式、长度、内部技术词和引用校验；第一次失败只重试一次，仍失败返回“当前数据不足以确认。”。
