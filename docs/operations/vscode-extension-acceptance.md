## 已验证链路

1. 扩展仅产生文件打开、编辑、保存、关闭、工作区变化和扩展变化元数据。
2. 文件事件在 Core 命名管道中按授权项目根目录相对化；未授权路径只返回固定拒绝码。
3. Core SQLite 队列只保存脱敏后的 AetherisEvent；事件正文和源代码不会进入扩展协议。
4. 部分确认只删除服务端接受的事件，失败事件留在本地队列。
5. 本地 Lens 支持安装、启用、停用、卸载和清除缓存；状态通过健康心跳回传 Admin Web。
6. Forge 将 VS Code 行为归一为 IDE/交付事实并生成 Work Episode 动作。
7. Nexus 文档仅包含活动类型、事件类型和安全摘要，不包含文件路径或字符数量。
8. Pulse 增加打开、编辑会话和保存三个解释性计数，按主体和设备聚合。
