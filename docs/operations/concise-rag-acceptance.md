# 简洁智能查询验收记录

- “线路有没有流量限制”归类为 `direct`，主答案只显示业务结论，默认不显示检索实现细节。
- “为什么线路会限速”归类为 `reason`，回答最多三个直接原因并保留引用。
- “详细说明限速实现和证据”归类为 `analysis`，允许展开详细说明。
- 主答案经过 JSON、模式、长度、内部技术词和引用编号校验；失败最多重试一次。
- 重试仍失败时返回“当前数据不足以确认。”，不透传模型原文。
- Admin Web 默认隐藏 Embedding、向量库、数据库、Worker 和日志连接状态；引用通过“查看依据”展开。
